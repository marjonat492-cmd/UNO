# UNO Game

A browser-based UNO game for one player against the computer. The complete game, including its styles and JavaScript, is in `index.html`.

## Run

Open `index.html` directly in a browser. No server or extra files are required.

## Features

- Two-player game: you versus the computer
- Standard UNO colors and number cards
- Wild and +4 cards
- Skip, reverse, and draw-two actions
- New game reset
